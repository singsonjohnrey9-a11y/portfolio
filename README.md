# John Rey Singson - Zine Portfolio

Personal portfolio of **John Rey Singson**, 4th year Information Technology
student at Cebu Eastern College, Cebu City.

- Live site: (deployed on Vercel - URL added below after deploy)
- Hosting: Vercel (free tier)
- Source: https://github.com/singsonjohnrey9-a11y/portfolio

## Stack

Plain HTML + CSS + vanilla JavaScript. No frameworks. Fonts via Google Fonts
(Permanent Marker, Space Grotesk, IBM Plex Mono). All animations are pure
CSS/JS (scroll reveal, marquee, stickers, easter egg: type `lain`).
